# GuideRail

A navegação entre as 12 guias de um nó, desenhada como o tronco de uma constelação: pontos ligados por uma linha que acende até a guia atual.

- Ordem fixa: Visão geral, Intuição, Analogia, Visualização, Quando usar, Complexidade, Exemplos, Código, Erros comuns, Exercícios, Resumo, Revisão.
- Ponto vazio = não lida; preenchido a 30% = lida; cheio com brilho = atual. A linha acesa cresce até a atual (`t-slow`).
- Fixa ao rolar (sticky) no desktop. Abaixo de 900px vira faixa horizontal no topo, e só a guia atual mostra o nome.
- ← → no teclado trocam de guia quando o foco não está no visualizador.

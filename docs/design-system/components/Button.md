# Button

Botão contornado: o primário usa a cor da área corrente (`--c`), o fantasma usa neutros.

- Altura 40px, raio `radius-md`, texto 14px peso 500. Nunca preenchido com cor sólida: no hover ganha um fundo a 12% e `glow-md`.
- Um primário por região (por exemplo "Abrir nó" no painel, a próxima guia no rodapé). Ações secundárias são fantasma.
- O texto diz o que acontece: "Abrir nó", "Ir para a casa", "Marcar como lida".
